# 14 — Виртуалка (гость)

> Минимальный набор для гостевой VM: обновление, Firefox, SSH (для подключения
> с хоста), Docker и opencode для кодинг-агентов.

---

## Шаг 1 — Обновление системы

```bash
sudo apt update && sudo apt upgrade -y
sudo apt autoremove -y
```

---

## Шаг 2 — Firefox, SSH и базовые утилиты

```bash
sudo apt install firefox openssh-server curl git -y
sudo systemctl enable --now ssh
```

SSH нужен для удобного подключения с хоста.

---

## Шаг 3 — Docker

Очистка и зависимости:

```bash
sudo apt remove docker docker-engine docker.io containerd runc -y 2>/dev/null
sudo apt install ca-certificates curl gnupg -y
```

GPG-ключ и репозиторий:

```bash
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

Установка:

```bash
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

---

## Шаг 4 — opencode

```bash
sudo snap install opencode --classic
```

---

## Шаг 5 — Перезагрузка

```bash
sudo reboot
```

Нужна для применения прав группы `docker`.
