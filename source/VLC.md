# VLC

> Универсальный медиаплеер, воспроизводит практически любой аудио- и видеоформат.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install vlc -y
```

---

## Шаг 2 — Проверка

```bash
vlc --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`vlc /path/to/video.mp4`|Открыть файл из терминала|
|`sudo apt update && sudo apt upgrade vlc`|Обновление|

---

## Устранение неполадок

### Нет звука или видео (аппаратное ускорение)

В **Инструменты → Настройки → Ввод/Кодеки** отключи «Аппаратное ускоренное декодирование» или переключи в `VDPAU`.
