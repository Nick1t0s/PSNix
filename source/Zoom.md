# Zoom

> Видеоконференции и онлайн-встречи. Устанавливается только из официального .deb, в репозитории Ubuntu его нет.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Скачать

Скачай пакет с официальной страницы:

**https://zoom.us/download?os=linux**

Файл: `zoom_amd64.deb` → попадёт в `~/Downloads`.

---

## Шаг 2 — Установка

```bash
sudo apt install ~/Downloads/zoom_amd64.deb -y
```

---

## Шаг 3 — Проверка

```bash
zoom --version
```

---

## Обновление

Zoom не обновляется через `apt` — периодически скачивай свежий `zoom_amd64.deb` и переустанавливай той же командой.

---

## Полезные команды

|Команда|Описание|
|---|---|
|`zoom`|Запустить из терминала|
|`dpkg -l zoom`|Проверить установленную версию|

---

## Устранение неполадок

### Ошибка зависимости при установке

```bash
sudo apt --fix-broken install
```
