# Vim

> Текстовый редактор из командной строки с модальным режимом работы.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install vim -y
```

---

## Шаг 2 — Проверка

```bash
vim --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`vim file.txt`|Открыть файл|
|`i`|Режим вставки|
|`Esc`|Выйти из режима вставки|
|`:wq`|Сохранить и выйти|
|`:q!`|Выйти без сохранения|
|`/слово`|Поиск|
|`u`|Отменить последнее действие|

---

## Устранение неполадок

### Стрелки работают как буквы

Это значит, что открыт `vim-tiny` вместо полного `vim`. Установи `vim` из репозитория (см. выше).
