# tmux

> Терминальный мультиплексор: несколько сессий, окон и панелей в одном терминале.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install tmux -y
```

---

## Шаг 2 — Проверка

```bash
tmux -V
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`tmux`|Запустить новую сессию|
|`tmux new -s имя`|Сессия с именем|
|`tmux attach -t имя`|Подключиться к сессии|
|`tmux ls`|Список сессий|
|`tmux detach` / `Ctrl+B D`|Отключиться (сессия остаётся жить)|
|`Ctrl+B C`|Новое окно|
|`Ctrl+B %`|Вертикальная панель|
|`Ctrl+B "`|Горизонтальная панель|
|`Ctrl+B Z`|Развернуть панель на весь экран|
