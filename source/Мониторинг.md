# Мониторинг

> Утилиты для наблюдения за системой: CPU, GPU, диски, процессы и сеть.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install btop nvtop iotop nload iftop nethogs powerstat -y
```

- `btop` — современный монитор CPU/RAM/дисков/сети (замена htop)
- `nvtop` — мониторинг видеокарт (NVIDIA/AMD/Intel)
- `iotop` — нагрузка на диск по процессам
- `nload` — скорость сети в реальном времени
- `iftop` — сетевой трафик по соединениям
- `nethogs` — сетевой трафик по процессам
- `powerstat` — измерение энергопотребления (требует `sudo powerstat`)

---

## Шаг 2 — Проверка

```bash
btop --version
nvtop --version
iotop --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`btop`|Запустить монитор|
|`nvtop`|Мониторинг GPU|
|`sudo iotop`|Нагрузка на диск по процессам|
|`nload`|Скорость сети по интерфейсам|
|`sudo iftop`|Трафик по соединениям|
|`sudo nethogs`|Трафик по процессам|

> `iotop`, `iftop` и `nethogs` требуют `sudo`.
