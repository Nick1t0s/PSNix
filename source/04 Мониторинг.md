# 04 — Мониторинг

> Наблюдение за системой: CPU, GPU, диски, процессы, сеть и энергопотребление.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt install htop btop nvtop iotop nload iftop nethogs powerstat -y
```

- `htop` — интерактивный просмотрщик процессов
- `btop` — современный монитор CPU/RAM/дисков/сети
- `nvtop` — мониторинг видеокарт (NVIDIA/AMD/Intel)
- `iotop` — нагрузка на диск по процессам
- `nload` — скорость сети в реальном времени
- `iftop` — сетевой трафик по соединениям
- `nethogs` — сетевой трафик по процессам
- `powerstat` — измерение энергопотребления

---

## Шаг 2 — Проверка

```bash
htop --version
btop --version
nvtop --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`htop`|Процессы (`F6` сортировка, `F5` дерево, `F9` убить)|
|`btop`|Современный монитор|
|`nvtop`|Мониторинг GPU|
|`sudo iotop`|Диск по процессам|
|`nload`|Скорость сети по интерфейсам|
|`sudo iftop`|Трафик по соединениям|
|`sudo nethogs`|Трафик по процессам|
|`sudo powerstat`|Энергопотребление|

> `iotop`, `iftop` и `nethogs` требуют `sudo`.
