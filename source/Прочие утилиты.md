# Прочие утилиты

> Дополнительный набор: обработка изображений, синхронизация, сетевые ФС и бэкапы.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install imagemagick rsync sshfs timeshift -y
```

- `imagemagick` — пакетная обработка изображений из командной строки
- `rsync` — синхронизация файлов и папок (локально и по сети)
- `sshfs` — монтирование удалённой папки через SSH как локальную
- `timeshift` — создание снапшотов системы для отката

---

## Шаг 2 — Проверка

```bash
magick --version
rsync --version | head -n1
sshfs --version
timeshift --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`magick input.png -resize 800x out.jpg`|Изменить размер и конвертировать|
|`magick input.png -quality 80 out.jpg`|Сжать JPEG|
|`rsync -av папка/ /куда/`|Синхронизировать с подробным выводом|
|`sshfs user@host:/путь ~/mnt`|Смонтировать удалённую папку|
|`fusermount -u ~/mnt`|Размонтировать|
|`sudo timeshift --create`|Создать снапшот вручную|
