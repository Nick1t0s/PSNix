# 08 — Сеть и синхронизация

> SSH-сервер, общие папки Samba, синхронизация файлов Syncthing
> и прокси/VPN-клиент Nekoray.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — OpenSSH-сервер

```bash
sudo apt install openssh-server -y
sudo systemctl enable --now ssh
```

Проверка: `systemctl status ssh --no-pager` (`active (running)`) и `ss -tlnp | grep :22`.

Если включён UFW: `sudo ufw allow ssh && sudo ufw reload`.

Копирование ключей с другой машины: `ssh-copy-id nik@192.168.x.x`.

---

## Шаг 2 — Samba (SMB-шары)

```bash
sudo apt install samba smbclient -y
sudo systemctl enable --now smbd
sudo smbpasswd -a $USER    # пароль SMB задаётся отдельно от системного
```

Проверка:

```bash
testparm
smbclient -L localhost -U $USER
```

Конфиг: `/etc/samba/smb.conf`. Если шара не видна с Windows — `sudo ufw allow samba`.

---

## Шаг 3 — Syncthing (официальный репозиторий, stable-v2)

```bash
sudo mkdir -p /etc/apt/keyrings
sudo curl -L -o /etc/apt/keyrings/syncthing-archive-keyring.gpg https://syncthing.net/release-key.gpg
echo "deb [signed-by=/etc/apt/keyrings/syncthing-archive-keyring.gpg] https://apt.syncthing.net/ syncthing stable-v2" | sudo tee /etc/apt/sources.list.d/syncthing.list
sudo apt update
sudo apt install syncthing -y
```

Запуск как пользовательский сервис:

```bash
systemctl --user enable syncthing
systemctl --user start syncthing
```

Веб-интерфейс: `http://127.0.0.1:8384`.

## Шаг 4 — Nekoray (прокси/VPN, .deb)

> Репозиторий [MatsuriDayo/nekoray](https://github.com/MatsuriDayo/nekoray) архивирован,
> последний релиз — **3.26**. TUN-режим работает только в `.deb` (AppImage не поддерживает TUN).

```bash
sudo apt install libxcb-xinerama0
curl -L -O https://github.com/MatsuriDayo/nekoray/releases/download/3.26/nekoray-3.26-2023-12-09-debian-x64.deb
sudo apt install ./nekoray-3.26-2023-12-09-debian-x64.deb
```

Запуск из меню — «NekoRay». TUN включается в настройках ядра (нужны права root).

> На ПК при поднятом TUN Docker остаётся доступным через `fix-docker-vpn` —
> см. `13 Только для ПК.md`.

## Полезные команды

|Команда|Описание|
|---|---|
|`sudo systemctl restart ssh`|Перезапуск SSH после правки конфига|
|`sudo smbpasswd -a nik`|Добавить SMB-пароль пользователю|
|`smbclient //host/share -U nik`|Подключиться к шаре|
|`systemctl --user status syncthing`|Статус Syncthing|
