# Git

> Система контроля версий: отслеживание изменений кода, ветки, история и совместная работа.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install git git-lfs -y
```

`git-lfs` — расширение для работы с большими файлами (бинарники, архивы, модели).

---

## Шаг 2 — Проверка

```bash
git --version
git lfs version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`git clone URL`|Склонировать репозиторий|
|`git init`|Инициализировать репозиторий в папке|
|`git status`|Текущее состояние|
|`git add .`|Добавить все изменения в индекс|
|`git commit -m "сообщение"`|Создать коммит|
|`git push` / `git pull`|Отправить / получить изменения|
|`git log --oneline`|История коммитов одной строкой|
|`git checkout -b имя`|Создать и переключиться на ветку|
