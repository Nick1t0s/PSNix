# Базовые утилиты

> Набор сетевых и архивных утилит: скачивание файлов, архивация и распаковка.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install curl wget unzip p7zip-full -y
```

- `curl` — скачивание/отправка данных по сети (HTTP, FTP и др.)
- `wget` — рекурсивное скачивание страниц и файлов
- `unzip` — распаковка ZIP-архивов
- `p7zip-full` — работа с 7z и другими форматами архивов

---

## Шаг 2 — Проверка

```bash
curl --version | head -n1
wget --version | head -n1
unzip -v | head -n1
7z | head -n2
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`curl -L -o файл URL`|Скачать файл по URL|
|`curl -s URL`|Показать ответ без прогресс-бара|
|`wget URL`|Скачать файл|
|`wget -c URL`|Продолжить прерванное скачивание|
|`unzip архив.zip`|Распаковать архив|
|`7z x архив.7z`|Распаковать 7z|
|`7z a архив.7z папка/`|Создать архив 7z|
