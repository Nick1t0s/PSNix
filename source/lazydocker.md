# lazydocker

> TUI для управления Docker: мониторинг контейнеров, логов и compose-проектов.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Docker (см. docker.md)

---

## Шаг 1 — Установка

```bash
curl https://raw.githubusercontent.com/jesseduffield/lazydocker/master/scripts/install_update_linux.sh | bash
```

---

## Шаг 2 — Проверка

```bash
lazydocker --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`lazydocker`|Запустить TUI|
