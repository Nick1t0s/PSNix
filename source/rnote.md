# 📒 Установка Rnote на Ubuntu через Snap

**Rnote** — это современное приложение для рукописных заметок и рисования, которое поддерживает страницы (а не бесконечный холст), вкладки и вставку изображений. Ниже приведена простая инструкция по установке с помощью встроенного пакетного менеджера **Snap**.

---

## 📋 Требования

- Ubuntu 16.04 LTS или новее (Snap предустановлен во всех современных версиях).
- Активное подключение к интернету.
- Права суперпользователя (sudo).

---

## ⚙️ Шаг 1. Проверка наличия Snap (если не установлен)

В большинстве версий Ubuntu Snap уже установлен по умолчанию. Чтобы проверить это, откройте терминал (`Ctrl+Alt+T`) и выполните:

```bash
snap --version
```

Если вы видите номер версии — всё в порядке, переходите к **Шагу 2**.

Если команда не найдена, установите Snap вручную:

```bash

sudo apt update
sudo apt install snapd
```
После установки перезагрузите систему или перезапустите сеанс, чтобы Snap-демон запустился корректно.

---

## 🚀 Шаг 2. Установка Rnote

В терминале выполните команду:

```bash

sudo snap install rnote
```
Snap автоматически загрузит последнюю стабильную версию приложения и все необходимые зависимости.

---

## ✅ Шаг 3. Запуск приложения

После завершения установки вы можете запустить Rnote:

- **Через графическое меню** — найдите значок «Rnote» в списке приложений.
    
- **Через терминал** — введите просто `rnote` и нажмите Enter.
    

Если вы хотите открыть Rnote с правами доступа к определённым папкам (например, для импорта/экспорта файлов), убедитесь, что Snap-пакет имеет соответствующие разрешения. При необходимости можно установить соединение с системными разделами через:

```bash

snap connect rnote:removable-media
```

---

## 🔄 Шаг 4. Обновление до новой версии

Snap автоматически обновляет приложения в фоновом режиме. Если вы хотите проверить наличие обновлений вручную, выполните:

```bash

sudo snap refresh rnote
```

---

## 🗑️ Шаг 5. Удаление Rnote (если потребуется)

Чтобы полностью удалить приложение, используйте команду:

```bash

sudo snap remove rnote
```

---

## ❗ Возможные проблемы и их решение

|Проблема|Решение|
|---|---|
|`snap: command not found`|Установите Snap, как показано в Шаге 1.|
|Ошибка `Permission denied` при установке|Запускайте команду с `sudo`.|
|Rnote не видит графический планшет|Проверьте, что планшет подключён до запуска приложения. При необходимости перезапустите Rnote.|
|Нет доступа к файлам вне домашней папки|Используйте `snap connect rnote:removable-media` или переместите файлы в `~/snap/rnote/current/`.|
