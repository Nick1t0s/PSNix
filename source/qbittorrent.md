# qBittorrent

> Бесплатный торрент-клиент с открытым исходным кодом.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt install qbittorrent -y
```

---

## Шаг 2 — Проверка

```bash
qbittorrent --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`qbittorrent`|Запустить из терминала|
|`sudo apt update && sudo apt upgrade qbittorrent`|Обновление|

---

## Устранение неполадок

### Загрузка через прокси/VPN не работает

В **Настройки → Соединение** укажи прокси или сетевой интерфейс VPN.
