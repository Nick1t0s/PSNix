# Zoom (ручная установка)

> ⚠️ Интерактивная установка: Zoom не распространяется через репозитории Ubuntu —
> `.deb` скачивается вручную с официального сайта. В репозитории его нет.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Скачать

Скачай пакет с официальной страницы:

**https://zoom.us/download?os=linux**

Файл: `zoom_amd64.deb` → попадёт в `~/Downloads`.

---

## Шаг 2 — Установка

```bash
sudo apt install ~/Downloads/zoom_amd64.deb -y
```

---

## Шаг 3 — Проверка

```bash
zoom --version
```

---

## Шаг 4 — Нативный диалог файлов (рекомендуется на Hyprland)

Qt+CEF-клиент Zoom уходит в терминальный файл-пикер. Чтобы вернуть нативный
диалог, создай `~/.local/share/applications/Zoom.desktop` (см. Шаг 6 в
`12 Hyprland и Waybar.md`) — он перекрывает системный ярлык и переживает обновления.

---

## Обновление

Zoom не обновляется через `apt` — периодически скачивай свежий `zoom_amd64.deb`
и переустанавливай той же командой из Шага 2.

---

## Устранение неполадок

- **Ошибка зависимостей при установке**: `sudo apt --fix-broken install`
- **`zoom` не запускается** — проверь версию: `dpkg -l zoom`
