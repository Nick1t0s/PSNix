# 06 — Заметки

> Приложения для заметок: Obsidian (Markdown-vault, .deb) и Rnote
> (рукописные заметки и рисование, snap).

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Obsidian (.deb с GitHub)

```bash
VER=$(curl -fsSL https://api.github.com/repos/obsidianmd/obsidian-releases/releases/latest | grep -oP '"tag_name":\s*"v\K[^"]+')
wget -O /tmp/obsidian.deb "https://github.com/obsidianmd/obsidian-releases/releases/download/v${VER}/obsidian_${VER}_amd64.deb"
sudo apt install /tmp/obsidian.deb -y
```

Или просто последний релиз:

```bash
wget https://github.com/obsidianmd/obsidian-releases/releases/latest/download/obsidian_amd64.deb
sudo apt install ./obsidian_amd64.deb -y
```

Устанавливается в `/opt/Obsidian`. Проверка: `obsidian --version`.

---

## Шаг 2 — Rnote (snap)

```bash
sudo snap install rnote
snap connect rnote:removable-media
```

`removable-media` — доступ к файлам вне домашней папки (импорт/экспорт со съёмных носителей).

---

## Обновление

- Obsidian: не обновляется через `apt` — скачай свежий `.deb` и переустанови той же командой.
- Rnote: `sudo snap refresh rnote`.

---

## Полезные команды

|Команда|Описание|
|---|---|
|`obsidian`|Запустить Obsidian|
|`rnote`|Запустить Rnote|
|`dpkg -l obsidian`|Версия Obsidian|
|`snap list rnote`|Версия Rnote|
