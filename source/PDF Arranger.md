# PDF Arranger

> Графический редактор PDF: объединение, разбиение, поворот, обрезка и перестановка страниц в PDF-файлах.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Установка

Пакет есть в стандартных репозиториях Ubuntu:

```bash
sudo apt install -y pdfarranger
```

---

## Запуск

|Команда|Описание|
|---|---|
|`pdfarranger`|Запустить из терминала|

Также появится ярлык в меню приложений.
