# 02 — Разработка

> Всё для разработки: Git и GitHub CLI, инструменты сборки, несколько версий
> Python, Node.js, редактор vim, AI-агент opencode, локальные LLM (Ollama)
> и JetBrains Toolbox.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Git, git-lfs, GitHub CLI

```bash
sudo apt install git git-lfs gh -y
```

- `git-lfs` — большие файлы (бинарники, модели)
- `gh` — репозитории, PR, issues прямо из терминала

Проверка:

```bash
git --version && git lfs version && gh --version
```

Авторизация gh (интерактивно): `gh auth login` → GitHub.com → HTTPS → Login with a web browser.

Если `gh` нет в репозитории:

```bash
(type -p wget >/dev/null || (sudo apt update && sudo apt-get install wget -y)) \
&& sudo mkdir -p -m 755 /etc/apt/keyrings \
&& out=$(mktemp) && wget -nv -O$out https://cli.github.com/keyring/githubcli-archive-keyring.gpg \
&& cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
&& sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
&& echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
&& sudo apt update && sudo apt install gh -y
```

## Шаг 2 — Инструменты сборки

```bash
sudo apt install build-essential cmake -y
```

`build-essential` — метапакет: `gcc`, `g++`, `make`, `dpkg-dev` и заголовочные файлы.

## Шаг 3 — Python (несколько версий, deadsnakes)

```bash
sudo add-apt-repository -y ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.9 python3.9-dev python3.9-venv \
                 python3.10 python3.10-dev python3.10-venv \
                 python3.11 python3.11-dev python3.11-venv \
                 python3.12 python3.12-dev python3.12-venv \
                 python3.13 python3.13-dev python3.13-venv -y
```

Системная версия (3.14 в Ubuntu 26.04) уже предустановлена.

Если `pip` не найден: `sudo apt install python3.13-pip -y` или `python3.13 -m ensurepip --upgrade`.

> Никогда не ставь пакеты в системный `python3` через `sudo pip` — используй venv:
> `python3.12 -m venv .venv && source .venv/bin/activate`.

## Шаг 4 — Node.js и npm

```bash
sudo apt install nodejs npm -y
```

В Ubuntu 26.04 ставится Node.js 22 LTS. Для управления версиями лучше nvm:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# после перезапуска терминала: nvm install --lts
```

> Не используй `sudo npm install -g` для глобальных пакетов — можно сломать права; лучше nvm.

## Шаг 7 — Ollama (локальные LLM)

Тихая установка, может занять несколько минут:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

Проверка: `which ollama && ollama --version`.

## Шаг 8 — JetBrains Toolbox (без sudo!)

> ⚠️ Toolbox ставится в домашнюю директорию пользователя — не используй `sudo` и не клади в `/opt`.

```bash
wget "https://download.jetbrains.com/toolbox/jetbrains-toolbox-$(curl -fsSL 'https://data.services.jetbrains.com/products/releases?code=TBA&latest=true&type=release' | grep -o '"build":"[^"]*"' | head -n1 | cut -d'"' -f4).tar.gz"
mkdir -p ~/.local/share/JetBrains/Toolbox
rm -rf ~/.local/share/JetBrains/Toolbox/jetbrains-toolbox-*
tar -xzf jetbrains-toolbox-*.tar.gz -C ~/.local/share/JetBrains/Toolbox
~/.local/share/JetBrains/Toolbox/jetbrains-toolbox-*/bin/jetbrains-toolbox
rm -f ~/jetbrains-toolbox-*.tar.gz
```

При первом запуске прими пользовательское соглашение — после этого появится ярлык в меню.
