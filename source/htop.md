# htop

> Интерактивный просмотрщик процессов и использования CPU/RAM в терминале.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Установка

```bash
sudo apt update
sudo apt install htop -y
```

---

## Шаг 2 — Проверка

```bash
htop --version
```

---

## Полезные команды

|Команда|Описание|
|---|---|
|`htop`|Запустить|
|`F6`|Сортировка по столбцу|
|`F5`|Дерево процессов|
|`F9`|Убить процесс|
|`F10`|Выход|
