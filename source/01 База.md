# 01 — База: обновление системы и базовые утилиты

> Первая группа на свежей системе: обновление всего, сетевые/архивные утилиты,
> обработка изображений, синхронизация и бэкапы.

---

## Требования

- Ubuntu / Debian / Linux Mint
- Права `sudo`

---

## Шаг 1 — Обновление системы

```bash
sudo apt update && sudo apt upgrade -y
sudo apt autoremove -y
```

---

## Шаг 2 — Базовые утилиты (сеть и архивы)

```bash
sudo apt install curl wget unzip -y
```

- `curl` — скачивание/отправка данных по сети (HTTP, FTP и др.)
- `wget` — рекурсивное скачивание страниц и файлов
- `unzip` — распаковка ZIP-архивов

### 7-Zip

Ubuntu 26.04: `p7zip-full` убран из репозитория, заменён на `7zip`:

```bash
sudo apt install 7zip -y || sudo apt install p7zip-full -y
```

Проверка: `7z | head -n2`.

---

## Шаг 3 — Прочие утилиты (изображения, синхронизация, бэкапы)

```bash
sudo apt install imagemagick rsync sshfs timeshift -y
```

- `imagemagick` — пакетная обработка изображений из командной строки
- `rsync` — синхронизация файлов и папок (локально и по сети)
- `sshfs` — монтирование удалённой папки через SSH как локальную
- `timeshift` — снапшоты системы для отката

---

## Шаг 4 — rust-coreutils (опционально)

Переписанные на Rust стандартные утилиты Unix (ls, cp, mv, cat и т.д.):

```bash
sudo apt install rust-coreutils -y
```

Ставятся рядом со стандартными, не заменяя их — вызывай через префикс `uutils`.
Проверка: `uutils --version`.

---

## Проверка

```bash
curl --version | head -n1
wget --version | head -n1
7z | head -n2
magick --version | head -n1
rsync --version | head -n1
timeshift --version
```

## Полезные команды

|Команда|Описание|
|---|---|
|`curl -L -o файл URL`|Скачать файл по URL|
|`wget -c URL`|Продолжить прерванное скачивание|
|`7z x архив.7z`|Распаковать 7z|
|`magick input.png -resize 800x out.jpg`|Изменить размер и конвертировать|
|`rsync -av папка/ /куда/`|Синхронизировать с подробным выводом|
|`sshfs user@host:/путь ~/mnt`|Смонтировать удалённую папку|
|`fusermount -u ~/mnt`|Размонтировать|
|`sudo timeshift --create`|Создать снапшот вручную|
